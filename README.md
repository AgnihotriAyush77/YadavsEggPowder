# YADAV'S — Egg Powder Website

A bright, cartoon-inspired, responsive landing page for the YADAV'S egg powder brand.

## Features
- Scroll-driven egg animation: the egg spins, dissolves into golden powder particles, and the particles fall into the product pouch.
- Responsive layout for desktop, tablet and mobile.
- Product benefits, indicative nutrition panel, Yadav Poultry Farm sourcing story, recipe-use ideas and launch CTA.
- Accessible reduced-motion fallback and semantic page sections.
- No framework or build step required.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. For a local server, run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Deploy with GitHub Pages
1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to appear.

## Important product-content notes
- The nutrition panel is an indicative reference estimate for whole egg powder, not laboratory-tested YADAV'S product data. Replace it with verified lab results before commercial packaging or advertising.
- The pack illustration is a concept. The displayed 500 g weight in the animation is illustrative; confirm actual pack size before launch.
- The Buy Now CTA currently opens a launch-soon dialog. No payment gateway or order processing is connected.
- Confirm food-safety processing, shelf life, ingredient declarations, allergen statements and applicable FSSAI labelling before sale.

## Brand sourcing statement
The page states that eggs are freshly sourced through **Yadav Poultry Farm**, as supplied by the brand owner.
